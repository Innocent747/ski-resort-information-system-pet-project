# Ski Resort Information System

## О проекте

Информационная система управления горнолыжным курортом, разработанная в рамках дисциплины «Проектирование информационных систем».

Цель проекта — автоматизация процессов управления горнолыжным курортом, включая учет клиентов, бронирование услуг, мониторинг состояния трасс и формирование отчетности.

Проект охватывает основные этапы анализа и проектирования информационной системы: исследование предметной области, моделирование бизнес-процессов, проектирование базы данных и разработку UML-моделей.

---

## Цели проекта

- Автоматизация процесса бронирования услуг.
- Управление данными клиентов и инструкторов.
- Мониторинг состояния горнолыжных трасс.
- Формирование аналитической отчетности.
- Повышение эффективности управления курортом.
